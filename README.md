При запуске проекта загадывается случайным образом число или цифра от 1 до 100, пользователь должен его угадать. Если пользователь не угадывает число, выводится соответствующая подсказка ("Больше загаданного!" или "Меньше загаданного!"); если пользователь пишет загаданное число, проект пишет "Угадал!" и выводит количество попыток, понадобившееся для угадывания числа.
